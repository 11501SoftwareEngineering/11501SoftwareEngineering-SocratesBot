# API 功能規格

## 全域規範

- Base URL: `/api/v1`
- 認證機制: Bearer Token (JWT), Request Header: `Authorization: Bearer <access_token>`
- 角色定義: 學生 (STUDENT)、老師 (TEACHER)、管理員 (SUPER_ADMIN)

---

## 全站通用與身份驗證模組

### 使用者註冊
- 功能說明: 新使用者建立帳號
- 呼叫方式: POST /auth/register
- 輸入資料: 帳號, 密碼, 姓名
- 成功回應: 帳號, 姓名, 角色, 回應訊息
- 錯誤:
    - 帳號或密碼未填寫或格式不符
    - 帳號已存在

### 使用者登入
- 功能說明: 帳號密碼驗證並取得登入憑證
- 呼叫方式: POST /auth/login
- 輸入資料: 帳號, 密碼
- 成功回應: 登入憑證, 使用者資訊: 帳號, 姓名, 角色, 偏好語言
- 錯誤:
    - 帳號或密碼未輸入
    - 帳號或密碼錯誤
    - 帳號已停用

### 取得當前使用者資訊
- 功能說明: 取得已登入使用者的個人資訊（用於頁面重整及 Header 顯示帳號）
- 呼叫方式: GET /users/me
- 輸入資料: 無
- 成功回應: 帳號, 姓名, 角色, 偏好語言
- 錯誤:
    - 未登入或憑證過期

### 修改密碼
- 功能說明: 已登入使用者變更密碼
- 呼叫方式: PUT /auth/password
- 輸入資料: 舊密碼, 新密碼
- 成功回應: 回應訊息
- 錯誤:
    - 新密碼格式不符
    - 未登入或憑證過期
    - 原密碼輸入錯誤

### 更新使用者偏好
- 功能說明: 更新使用者介面偏好語言
- 呼叫方式: PATCH /users/me/preferences
- 輸入資料: 語言設定
- 成功回應: 偏好語言, 回應訊息
- 錯誤:
    - 語言代碼無效
    - 未登入或憑證過期

### 送出 Bug 回報
- 功能說明: 使用者送出系統問題回報
- 呼叫方式: POST /system/bug-reports
- 輸入資料: 標題, 描述, 環境資訊: 瀏覽器, 作業系統, 當前網址
- 成功回應: 回報單號, 回應訊息
- 錯誤:
    - 標題或內容為空、字數超過上限

## 學生端

### 課程

#### 取得我的課程列表
- 功能說明: 學生主頁取得已加入的課程清單
- 呼叫方式: GET /student/courses
- 輸入資料: 無
- 成功回應: 課程清單，包含 課程代號, 課程名稱, 課程邀請碼, 授課老師姓名, 進行中題目數量
- 錯誤:
    - 未登入或憑證過期
    - 非學生身分無權存取

#### 透過代碼加入課程
- 功能說明: 學生輸入課程代碼加入新課程
- 呼叫方式: POST /student/courses/join
- 輸入資料: 課程邀請碼
- 成功回應: 課程代號, 課程名稱, 課程邀請碼, 回應訊息
- 錯誤:
    - 代碼格式無效
    - 未登入或憑證過期
    - 查無此代碼對應的課程
    - 已經是該課程成員

#### 學生退出課程
- 功能說明: 學生主頁刪除/退選已加入的課程
- 呼叫方式: DELETE /student/courses/{courseId}
- 輸入資料: 無
- 成功回應: 回應訊息
- 錯誤:
    - 未登入或憑證過期
    - 查無此課程或未加入此課程

#### 取得學生課程資訊與問題列表
- 功能說明: 學生課程頁面取得課程代碼與問題列表
- 呼叫方式: GET /student/courses/{courseId}/topics
- 輸入資料: 無
- 成功回應: 課程代號, 課程名稱, 課程邀請碼, 題目清單，包含 題目代號, 標題, 描述, 狀態, 對話代號
- 錯誤:
    - 未登入或憑證過期
    - 尚未加入該課程
    - 查無此課程

### 對話

#### 建立或進入對話 Session
- 功能說明: 學生進入題目頁面開啟單一對話 Session
- 呼叫方式: POST /student/topics/{topicId}/sessions
- 輸入資料: 無
- 成功回應: 對話代號, 題目代號
- 錯誤:
    - 未登入或憑證過期
    - 尚未加入該題目所屬課程
    - 查無此題目

#### 取得題目背景知識
- 功能說明: 取得問題背景說明與關鍵思辨詞彙
- 呼叫方式: GET /student/topics/{topicId}/explanation
- 輸入資料: 無
- 成功回應: 標題, 背景說明, 關鍵思辨詞彙
- 錯誤:
    - 未登入或憑證過期
    - 查無此題目

#### 蘇格拉底對話發送與串流回覆 (SSE)
- 功能說明: 學生打字回答問題，以串流方式接收 AI 反詰與引導訊息
- 呼叫方式: POST /student/sessions/{sessionId}/messages/stream
- 輸入資料: 回答內容
- 成功回應: 串流文字片段, 訊息代號, 是否為引導反詰
- 錯誤:
    - 訊息內容為空
    - 未登入或憑證過期
    - 無權存取此對話
    - 查無此對話

#### 語音辨識 (STT)
- 功能說明: 學生語音輸入轉為文字
- 呼叫方式: POST /student/audio/transcribe
- 輸入資料: 音檔
- 成功回應: 轉錄文字
- 錯誤:
    - 音訊檔案格式不符或損壞
    - 未登入或憑證過期
    - 音訊檔案超過容量限制

#### 取得學生個人結果頁
- 功能說明: 學生作答完成後取得論點摘要、立場轉折與核心論點
- 呼叫方式: GET /student/sessions/{sessionId}/result
- 輸入資料: 對話代號 (路徑參數)
- 成功回應: 對話代號, 題目代號, 歸屬結論立場, 是否匿名
- 錯誤:
    - 未登入或憑證過期
    - 非此對話擁有者
    - 查無此對話
    - 對話尚未完成無法生成結果

#### 更新匿名分享設定
- 功能說明: 學生切換是否匿名分享其結果至統計圖表
- 呼叫方式: PATCH /student/sessions/{sessionId}/privacy
- 輸入資料: 是否匿名
- 成功回應: 對話代號, 是否匿名, 回應訊息
- 錯誤:
    - 設定值無效
    - 未登入或憑證過期
    - 非此對話擁有者
    - 查無此對話

#### 學生取得題目長條圖統計與成員名單
- 功能說明: 學生查看題目長條圖統計數據，滑鼠懸停顯示各結論學生名單（匿名者自動顯示為匿名同學）
- 呼叫方式: GET /student/topics/{topicId}/analytics
- 輸入資料: 無
- 成功回應: 題目代號, 總作答人數, 長條圖統計清單，包含 結論代號, 結論標題, 人數, 百分比, 學生名單: 學生代號, 顯示名稱
- 錯誤:
    - 未登入或憑證過期
    - 尚未完成作答或未加入課程
    - 查無此題目

## 老師端模組

### 課程

#### 取得老師的課程列表
- 功能說明: 老師主頁取得開設的課程清單
- 呼叫方式: GET /teacher/courses
- 輸入資料: 無
- 成功回應: 課程清單，包含 課程代號, 課程名稱, 課程描述, 課程邀請碼, 學生人數, 題目數量
- 錯誤:
    - 未登入或憑證過期
    - 非老師身分無權存取

#### 老師建立新課程
- 功能說明: 老師建立新課程，系統自動產生課程代碼
- 呼叫方式: POST /teacher/courses
- 輸入資料: 課程名稱, 課程描述
- 成功回應: 課程代號, 課程名稱, 課程描述, 課程邀請碼, 回應訊息
- 錯誤:
    - 課程名稱未填寫
    - 未登入或憑證過期
    - 非老師身分無權存取

#### 老師刪除課程
- 功能說明: 老師主頁刪除指定課程
- 呼叫方式: DELETE /teacher/courses/{courseId}
- 輸入資料: 無
- 成功回應: 回應訊息
- 錯誤:
    - 未登入或憑證過期
    - 非該課程開課老師
    - 查無此課程

#### 取得特定課程問題列表
- 功能說明: 老師課程頁面取得課程代碼與問題列表
- 呼叫方式: GET /teacher/courses/{courseId}/topics
- 輸入資料: 無
- 成功回應: 課程代號, 課程名稱, 課程邀請碼, 題目清單，包含 題目代號, 標題, 描述, 結論數量, 學生回答人數
- 錯誤:
    - 未登入或憑證過期
    - 非老師身分無權存取
    - 查無此課程

#### 取得班級學生名單
- 功能說明: 取得課程的所有學生名單
- 呼叫方式: GET /teacher/courses/{courseId}/students
- 輸入資料: 無
- 成功回應: 學生清單，包含 學生代號, 姓名, 電子郵件, 加入時間
- 錯誤:
    - 未登入或憑證過期
    - 非該課程開課老師
    - 查無此課程

#### 手動將學生加入班級
- 功能說明: 老師手動將學生加入課程
- 呼叫方式: POST /teacher/courses/{courseId}/students
- 輸入資料: 學生代號
- 成功回應: 回應訊息
- 錯誤:
    - 學生代號未填寫
    - 未登入或憑證過期
    - 非該課程開課老師
    - 查無此學生或課程
    - 該學生已在課程中

#### 退選/移出學生
- 功能說明: 老師在問題頁面或班級管理中將學生從課程中移除（退選）
- 呼叫方式: DELETE /teacher/courses/{courseId}/students/{studentId}
- 輸入資料: 課程代號
- 成功回應: 回應訊息
- 錯誤:
    - 未登入或憑證過期
    - 非該課程開課老師
    - 查無此學生或課程

### 題目與結論

#### 建立/修改題目
- 功能說明: 老師在課程中新增或編輯討論題目
- 呼叫方式: POST /teacher/topics 或 PUT /teacher/topics/{topicId}
- 輸入資料: 課程代號, 標題, 描述, AI 引導提示詞
- 成功回應: 題目代號, 課程代號, 標題, 描述, 回應訊息
- 錯誤:
    - 標題或課程未填寫
    - 未登入或憑證過期
    - 非該課程開課老師
    - 查無此題目

#### 刪除題目
- 功能說明: 老師刪除課程中的討論題目
- 呼叫方式: DELETE /teacher/topics/{topicId}
- 輸入資料: 無
- 成功回應: 回應訊息
- 錯誤:
    - 未登入或憑證過期
    - 非該課程開課老師
    - 查無此題目

#### 取得題目結論列表與統計
- 功能說明: 老師問題頁面顯示各結論長條圖統計人數，滑鼠懸停顯示各結論學生名單
- 呼叫方式: GET /teacher/topics/{topicId}/conclusions
- 輸入資料: 無
- 成功回應: 題目代號, 總作答人數, 結論清單，包含 結論代號, 結論標題, 描述, 人數, 百分比, 學生名單: 學生代號, 顯示名稱
- 錯誤:
    - 未登入或憑證過期
    - 非老師身分無權存取
    - 查無此題目

#### 手動新增結論
- 功能說明: 老師新增題目分類結論
- 呼叫方式: POST /teacher/topics/{topicId}/conclusions
- 輸入資料: 結論標題, 結論描述
- 成功回應: 結論代號, 題目代號, 結論標題, 結論描述, 回應訊息
- 錯誤:
    - 結論標題未填寫
    - 未登入或憑證過期
    - 非該課程開課老師
    - 查無此題目

#### AI 生成結論建議
- 功能說明: 系統分析學生已提交的作答紀錄，由 AI 自動產生建議結論選項與描述
- 呼叫方式: POST /teacher/topics/{topicId}/generate-conclusions
- 輸入資料: 無
- 成功回應: 建議結論清單，包含 結論標題, 結論描述
- 錯誤:
    - 未登入或憑證過期
    - 非該課程開課老師
    - 查無此題目

#### 刪除結論
- 功能說明: 老師刪除指定題目下的特定結論
- 呼叫方式: DELETE /teacher/topics/{topicId}/conclusions/{conclusionId}
- 輸入資料: 題目代號
- 成功回應: 回應訊息
- 錯誤:
    - 未登入或憑證過期
    - 非該課程開課老師
    - 查無此題目或結論

#### 老師查看題目結果與個別論點摘要
- 功能說明: 老師結論結果頁面查看全體或單一結論學生之詳細作答論點
- 呼叫方式: GET /teacher/topics/{topicId}/analytics
- 輸入資料: 無
- 成功回應: 總作答人數, 結論分佈清單 (結論代號, 結論名稱, 人數, 百分比), 學生論點清單 (學生代號, 顯示名稱, 是否匿名, 結論代號, 結論名稱, 論點摘要)
- 錯誤:
    - 未登入或憑證過期
    - 非該課程開課老師
    - 查無此題目
