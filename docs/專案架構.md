# 專案結構

- 用 uv 管理 python 套件
- postgreSQL, redis 用 docker compose 容器

## 檔案目錄

- README.md
- docker-compose.yml
- docker-compose-prod.yml
- .gitignore
- .env.example
- backend/
    - pyproject.toml
    - Dockerfile
    - alembic/ 
    alembic 套件的資料庫遷移腳本
    - app/
        - api/v1/routes  
        HTTP 路由處理
        - core/
        系統全域性工具，包含 Pydantic Settings 設定檔載入、PostgreSQL 非同步連線、Redis 快取客戶端、密碼加密雜湊、JWT 、LLM api 設定與連接、enum、自訂 middleware
        - models/
        SQLAlchemy 2 資料表結構定義（Alembic 自動遷移的依據）
        - schemas/ 
        Pydantic v2 DTO，負責輸入校驗與回傳資料過濾
        - crud/
        資料庫 ORM 查詢操作
        - services/
        如AI 結論歸納計算、prompt 處理等商業邏輯處理。
        這裡不會包含資料庫操作，資料庫操作的部分會拆到 curd 裡，再由 service 去調用
- frontend/
前端
