# Gen Jyuu GothicX

Source: [genjyuugothic-subsets, release 2022-06-16](https://github.com/shogo82148/genjyuugothic-subsets/releases/tag/2022-06-16).
Original font: [Gen Jyuu Gothic, Jikasei Font Workshop](http://jikasei.me/font/genjyuu/).

Regular (400), Medium (500), and Bold (700) use the supplied WOFF2 files and unicode ranges.
Browsers load only the subsets needed for the displayed text. Files are hosted with the app.
Font outlines are unchanged; local file names and the CSS family alias are normalized.
See OFL.txt for the original copyright notices and SIL Open Font License.

Verified from the supplied Figma inspector screenshots:
- H2: 32px, 700, line-height 140%, letter-spacing 1%.
- H4: 20px, 500, line-height 100%, letter-spacing 0%.
- Body2: 16px, 400, line-height 160%, letter-spacing 0%.
- Botton_small: 22px, 500, line-height 100%, letter-spacing 0%.
The date style and shadow remain based on the existing project settings because their inspector values were not supplied.
